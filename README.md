# NordicPulse AI

NordicPulse AI analyses annual-report PDFs of Danish companies (Novo Nordisk, Ørsted, Vestas; fiscal years 2024 and 2025).
It extracts financial and ESG KPIs as Pydantic-validated JSON, each with its source page and quote, using hybrid retrieval (FAISS + BM25 + RRF) and deterministic normalization.
An agent answers comparative questions through a custom MCP server, and an automated evaluation with ablations measures the whole pipeline.
